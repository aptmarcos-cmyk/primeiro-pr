# Product

## Platform

web

## Stack

Delegated: no interface exists yet. When a surface is built, default to static HTML/CSS unless a specific need calls for a framework.

## Users

Developers (initially the repo owner) practicing the GitHub Pull Request workflow: cloning, branching, committing, and opening PRs.

## Product Purpose

A practice repository for learning and rehearsing the Git/GitHub Pull Request flow. It exists to give learners a safe, low-stakes place to open and merge PRs, not to ship a product feature.

## Operating Context

Used through standard Git tooling and the GitHub web UI/PR flow described in the README (clone → change → open PR).

## Capabilities and Constraints

No application code or UI exists yet. Whether this repo grows into a real product, versus staying a pure practice sandbox, is undecided.

## Product Principles

- Optimize for a clear, low-friction PR practice loop, not feature completeness.
- Keep the repo simple and legible for someone learning the workflow.
- Do not invent product scope beyond "practice the PR flow" until the owner defines one.

## Accessibility & Inclusion

No product-specific requirement established yet.
